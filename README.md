# بلک استار | Black Star — نسخه 0.1.0

اپلیکیشن آفلاین مدیریت مالی شخصی با رابط فارسی راست‌چین، پوسته تیره و جزئیات نئونی. این نسخه برای نمایش و آزمایش از داده‌های نمونه استفاده می‌کند؛ داده‌ها ذخیره نمی‌شوند و پایگاه‌داده هنوز اضافه نشده است.

## ساخت APK با GitHub Actions

1. کل پوشه پروژه را در یک مخزن GitHub قرار دهید و شاخه `main` (یا `master`) را push کنید.
2. در تب **Actions** اجرای گردش‌کار **Android CI** را باز کنید. ساخت APK به‌صورت خودکار انجام می‌شود.
3. پس از موفقیت، در بخش **Artifacts** همان اجرا، `blackstar-debug-apk` را دانلود و ZIP آن را باز کنید. فایل خروجی داخل آن `app-debug.apk` است.
4. برای ساخت دستی روی Linux/macOS با Java 17 و Android SDK نصب‌شده، در ریشه پروژه Gradle 8.9 را اجرا کنید: `gradle --no-daemon :app:assembleDebug`؛ خروجی در `app/build/outputs/apk/debug/app-debug.apk` قرار می‌گیرد.

## انتشار عمومی

برای دانلود عمومی، از **GitHub Releases** استفاده کنید: نسخه را tag کنید (برای نمونه `v0.1.0`)، APK را به‌عنوان دارایی Release منتشر کنید و لینک همان Release را به کاربران بدهید. فایل Artifacts مربوط به Actions برای خروجی موقت CI است و محل انتشار عمومی نسخه‌ها نیست.

## امضای برنامه

در v0.1.0، workflow فایل APK دیباگ را می‌سازد و برای آن secret امضا لازم نیست؛ پس از دانلود، Android ممکن است هنگام نصب APK دیباگ هشدار نصب نمایش دهد. پیش از انتشار نسخه تولیدی و به‌خصوص برای به‌روزرسانی کاربران، باید کلید release امن تهیه و امضای release و secretهای GitHub (مانند keystore و رمزهای آن) به workflow افزوده شوند. کلید امضا را در مخزن یا فایل‌های عمومی قرار ندهید. APKهای نسخه‌های بعدی برای نصب به‌روزرسانی باید با همان کلید انتشار امضا شوند.

## مشخصات

- Kotlin، Jetpack Compose و Material 3؛ `minSdk 26`، `compileSdk/targetSdk 35`، Java 17.
- خانه، تراکنش‌ها، حساب‌ها و تنظیمات؛ ناوبری و کنترل‌های نمونه فعال هستند.
- همه داده‌ها محلی و ثابت در کد هستند؛ بدون درخواست شبکه، تصویر اینترنتی یا پایگاه‌داده.
- افزودن سریع تراکنش در این نسخه فقط نمایشی است؛ ذخیره‌سازی در نسخه **v0.2.0** اضافه خواهد شد.
